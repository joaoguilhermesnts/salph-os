# Idiomas / Languages

## Português (Brasil)

### Trocar o idioma
- **No boot da ISO:** escolha "SALPH OS Live" (pt-BR) ou "SALPH OS Live (English, US)".
- **Só para você:** Configurações → Região e idioma → Idioma. Saia e entre de novo.
- **Para o sistema todo:**
  ```bash
  salph-locale en-US --keyboard us
  salph-locale pt-BR --keyboard br
  ```
  Pede a senha de administrador. Use `--user-only` para não alterar o padrão do sistema.

### Traduzir strings novas
1. Em scripts de `src/`, marque o texto com `gettext "..."` (ou
   `printf "$(gettext '... %s')" "$valor"` quando houver variável). Escreva o msgid em inglês.
2. `tools/l10n.sh pot && tools/l10n.sh update`
3. Edite `po/pt_BR.po` (e `po/en_US.po`, que normalmente repete o inglês).
4. `tools/l10n.sh check` — precisa mostrar todas as mensagens traduzidas.

O build (`build.sh`) compila os catálogos automaticamente.

## English (US)

### Switching language
- **At ISO boot:** pick "SALPH OS Live" (pt-BR) or "SALPH OS Live (English, US)".
- **Just for you:** Settings → Region & Language → Language. Log out and back in.
- **System-wide:**
  ```bash
  salph-locale en-US --keyboard us
  salph-locale pt-BR --keyboard br
  ```
  Asks for the administrator password. Add `--user-only` to leave the system default alone.

### Translating new strings
1. In `src/` scripts, wrap text with `gettext "..."` (or
   `printf "$(gettext '... %s')" "$value"` for variables). Write msgids in English.
2. `tools/l10n.sh pot && tools/l10n.sh update`
3. Edit `po/pt_BR.po` (and `po/en_US.po`, usually identical to the English text).
4. `tools/l10n.sh check` — every message must be translated.

`build.sh` compiles the catalogs automatically.
